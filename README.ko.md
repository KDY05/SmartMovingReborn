# Smart Moving Reborn

[English](README.md) | 한국어

Divisor의 **Smart Moving**을 Minecraft 1.20.1(Forge, Fabric)과 1.21.1(NeoForge, Fabric)로 옮긴 모드입니다.
기어가기, 등반, 천장 등반, 슬라이딩, 벽 점프, 차지 점프, 다이빙 등을 원작 애니메이션과 함께 추가합니다.

## 요구 사항

| Minecraft | 로더 | 소스 브랜치 |
|---|---|---|
| 1.20.1 | Forge 47.x, 또는 Fabric Loader와 Fabric API | [`1.20.1`](https://github.com/kdy05/SmartMovingReborn/tree/1.20.1) |
| 1.21.1 | NeoForge 21.1.x, 또는 Fabric Loader와 Fabric API | [`1.21.1`](https://github.com/kdy05/SmartMovingReborn/tree/1.21.1) |

- **클라이언트와 서버 모두에** 설치해야 합니다. 한쪽에만 있어도 접속은 되지만 Smart Moving은 비활성화됩니다.
- 1.21.1에서는 Fabric과 NeoForge 클라이언트·서버가 서로 접속해도 Smart Moving이 동작합니다.

## 조작법

| 동작 | 키 |
|---|---|
| 잡기(Grab) | **왼쪽 Ctrl** (Smart Moving 전용 키) |
| 스프린트(Smart Moving) | 바닐라 달리기 키. 모드가 기본값을 **R**로 바꿉니다 |
| 달리기(바닐라 스프린트) | 앞 키 두 번 |
| Smart Moving 켜기/끄기 | **F9** |
| 등반 | 잡을 곳이 있는 벽을 보고 잡기를 누른 채 유지. 앞 키로 오르고, 뒤 키를 누르거나 키를 떼면 내려갑니다 |
| 등반 중 매달리기 | Shift + 잡기 |
| 천장 등반 | 철창이나 다락문 아래에서 잡기를 누른 채 유지 |
| 기어가기 | 땅에서 Shift + 잡기. 한 칸 높이 틈에 들어가면 저절로 기어갑니다 |
| 슬라이딩 | 달리기나 스프린트 중 Shift + 잡기 |
| 차지 점프 | 서서 Shift와 점프를 누르고 있다가 점프를 뗌 |
| 옆/뒤 점프 | 왼쪽, 오른쪽, 뒤 키 두 번 (왼쪽·오른쪽 + 뒤는 대각선) |
| 헤드 점프 | 달리기나 스프린트 중 잡기를 누른 채 점프를 눌러 모았다가 뗌 |
| 벽 점프 | 공중에서 점프를 두 번 누르고 벽에 부딪힐 때까지 유지. 잡기도 누르고 있으면 벽 헤드 점프 |

잡기와 F9는 바닐라 조작 설정 화면에서 바꿀 수 있습니다. 왼쪽 Ctrl은 바닐라 달리기 키의 기본값이라, 모드가 바닐라 달리기 키의 기본값을 R로 옮깁니다.

## 기능

- **자유 등반**: 벽 틈, 반블록, 계단, 울타리, 돌담, 판유리, 다락문, 문 등을 오를 수 있습니다.
- **천장 등반**: 철창과 다락문. 블록 목록은 설정으로 바꿀 수 있고 블록 태그도 쓸 수 있습니다.
- **기어가기**: 한 칸 높이 틈에서 기어가며, 바닐라의 자동 기어가기를 대신합니다.
- **슬라이딩**과 **헤드 점프**: 끝나면 기어가기나 활공으로 이어집니다.
- **점프**: 차지 점프, 옆·뒤 점프, 등반 점프, 벽 점프와 벽 헤드 점프.
- **스프린트**(1.5배): 땅 위뿐 아니라 등반, 수영, 다이빙, 천장 등반, 비행 중에도 쓰이며 시야 범위가 바뀝니다.
- **수영, 다이빙, 얕은 물 걷기**: 바닐라의 수영을 대신합니다.
- **비행**: 크리에이티브에서 시선 방향대로 날고, 전용 부양 및 낙하 애니메이션이 있습니다.
- **서버 규칙 강제**: `move.server.config`를 켜면 접속해 있는 동안 서버의 이동 설정이 각 클라이언트의 설정을 강제합니다.

## 설정

게임 안 설정 화면은 없습니다. `config/` 폴더의 파일을 고친 뒤 게임이나 서버를 다시 시작하세요.

| 파일 | 내용 |
|---|---|
| `smartmovingreborn-client.properties` | 이동 설정과 클라이언트 전용 설정(시점과 시야각, 두 번 누르기 간격, 토글, 채팅 메시지, 디버그) |
| `smartmovingreborn-server.properties` | 같은 이동 설정과 `move.server.config` |

각 설정의 설명은 파일 안 주석에 있습니다. 키 이름과 기본값은 원작의 "Easy" 프리셋을 따릅니다. 잘못된 값은 기본값으로, 범위를 벗어난 값은 범위 안으로 바뀌고, 로그에 어떤 값인지 남습니다.

- 클라이언트에도 서버 파일이 생깁니다. 싱글플레이와 LAN 월드는 내장 서버가 이 파일을 읽습니다.
- `move.server.config=true`이면 접속한 모든 플레이어에게 나갈 때까지 서버의 이동 설정이 적용됩니다. 클라이언트 전용 설정은 항상 각자의 것을 씁니다.

## 원작과 다른 점

- **Easy** 프리셋만 옮겼습니다. 피로도와 허기가 없고, F9는 프리셋을 바꾸는 대신 Smart Moving을 켜고 끕니다.
- 왼쪽 Ctrl이 잡기 키라서 달리기 기본 키가 **R**입니다.
- 원작 버그 몇 가지를 고쳤습니다. 주로 벽 점프 각도와 등반 잡을 곳 판정입니다.
- 1.21.1에서 크기(scale) 속성이 1이 아닌 플레이어는 바닐라처럼 움직입니다.
- 옮기지 않은 것: 게임 안 속도 조절 키, 프리셋과 사용자별 권한, 용암 수영, 더 이상 없는 모드와의 호환(Ropes+, Carpenter's Blocks 등).

## 번역

영어와 한국어. 추가로 네덜란드어, 브라질 포르투갈어, 러시아어는 원작의 번역(Dunncann, Cassiobsk8, _DarKShaM_)을 사용합니다.
